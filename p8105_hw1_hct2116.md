When taking the means, the means of numeric and logical variables could
be calculated, but not for the character and factor variables.

``` r
as.numeric(pull(df, logical))
as.numeric(pull(df, character))
```

    ## Warning: NAs introduced by coercion

``` r
as.numeric(pull(df, factor))
```

Applying `as.numeric()` to the logical variable converts `TRUE` to 1 and
`FALSE` to 0.  
Applying `as.numeric()` to the character variable leads to `NA` values
because the character values can’t be converted into numbers.  
Applying `as.numeric()` to the factor variable converts the factor to
their level integer codes rather than converting the labels themselves
into numbers.  
It helps explain the previous output of taking the mean. It works for
logical values because they are treated as numbers (0 and 1), while
character and factor variables do not directly provide numeric values
when calculating a mean.
